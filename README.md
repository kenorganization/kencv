## 🚀 專案描述

這是一個響應式個人履歷網站，展示跨領域全端工程師的專業技能與經驗。從實驗室研發到程式開發，融合科學與創意的職涯歷程。

**網站特色：**

- 🎨 現代化響應式設計
- ⚡ 流暢的動畫效果
- 📱 完美支援行動裝置
- 🔍 SEO 優化設定
- 🌐 社交媒體整合

## 🛠️ 技術棧

### 前端技術

- **框架**: Bootstrap 5.3.3
- **動畫**: AOS (Animate On Scroll)
- **圖片展示**: GLightbox
- **輪播**: Swiper.js
- **佈局**: Isotope Layout
- **圖示**: Bootstrap Icons
- **計數動畫**: PureCounter

### 開發工具

- **版本控制**: Git
- **程式碼編輯器**: VS Code
- **瀏覽器相容性**: Chrome, Firefox, Safari, Edge

## 🚀 快速開始

### 1. 複製專案

```bash
git clone https://github.com/kenorganization/kencv.git
cd kencv
```

### 2. 開啟網頁

直接在瀏覽器中開啟 `index.html` 或使用本地伺服器：

```bash
# 使用 Python 簡易伺服器
python -m http.server 8000

# 或使用 Node.js http-server
npx http-server
```

### 3. 瀏覽網站

開啟瀏覽器前往 `http://localhost:8000`

## 🌐 部署選項

### GitHub Pages

1. 前往 GitHub 儲存庫設定
2. 選擇 Pages 設定
3. 選擇 main 分支作為來源
4. 網站將部署至 `https://kenorganization.github.io/kencv/`
